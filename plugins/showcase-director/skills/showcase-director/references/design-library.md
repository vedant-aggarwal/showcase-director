# Optional local design skills

Ask for a path only when it cannot be retrieved from current project instructions. Start at the library index; load a small, relevant set. Do not import or publish an entire collection.

Useful roles:

- Apple design: spatial continuity, clear typography, responsive preview controls, meaningful depth.
- Product-proof design: show the mechanism, input, state change and outcome; qualify sample outputs.
- Cinematic storytelling: camera handoffs, visual hierarchy and progressive reveals. Translate scroll effects into seekable video timing.
- Animation guidance: precise easing, stagger and state timing rather than adjectives alone.
- Interface polish: focus, hit targets, control states, reduced motion and optical alignment in the player.

Record the selected skill names, source paths and the decisions they informed in the private project's `DESIGN.md`. Public plugin documentation should use generic roles or public upstream links, not a user's absolute paths or private repository.

Resolve conflicts by medium and user intent. Apple-inspired film direction can coexist with the product's established colors and component styling. Existing application UI remains the reference for reconstructed screens. A web skill's timers, hover-only behavior, scrolling libraries and page preloaders usually do not belong in a rendered film.

The bundled original direction guide is the fallback when no local library exists. Do not claim optional skills were loaded when they were unavailable.
