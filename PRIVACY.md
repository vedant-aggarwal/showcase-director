# Privacy

This plugin has no hosted backend, MCP server, analytics, credential store or automatic publisher. Its bundled helpers read and write local project files. Scaffolding does not contact the network.

The user’s agent and separately installed Hyperframes runtime may use their own services or telemetry. Installing npm dependencies contacts npm. Product research and optional asset tools follow the agent's current permissions. Do not place credentials, customer records, private captures or confidential source in a public showcase repository. Use synthetic fixtures or explicitly authorized, sanitized captures.
